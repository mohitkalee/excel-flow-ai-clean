# Excel Flow AI

You are a world-class SaaS product designer, UX strategist, and conversion-focused web developer with deep knowledge of human psychology, UI/UX, and high-performing SaaS businesses.



Your task: Design and generate a complete, high-converting website for an AI SaaS tool that automatically cleans and organizes Excel/CSV data.



## PRODUCT CONTEXT:

Product Name: Excel flow Ai

Core Function:

- Removes duplicates

- Fixes formatting (dates, numbers, columns)

- Standardizes messy datasets

- Accepts custom instructions (e.g., “split full names”, “clean phone numbers”)



Target Users:

- Small businesses

- E-commerce sellers

- Agencies

- Accountants



Core Value Proposition:

👉 Saves hours of manual work  

👉 Replaces repetitive data entry  

👉 Increases accuracy instantly  



Process Flow:

Upload file → AI cleans → Download clean file



---



## GOAL:

Create a clean, modern, highly trustworthy SaaS website that maximizes:

- Conversions (free trial / signup)

- User trust

- Perceived value (automation replacing humans)

- Simplicity (non-technical users)



---



## DESIGN & BRANDING REQUIREMENTS:



### Visual Style:

- Clean, minimal, professional (inspired by Stripe, Notion, OpenAI)

- Plenty of whitespace

- Soft shadows, rounded edges (modern SaaS feel)

- Color palette: 

  - Primary: Blue or Purple (trust + intelligence)

  - Secondary: Light grey/white background

  - Accent: Green (success/action)

- Typography: Simple, modern (Inter, Poppins)



### Psychological Triggers:

- Trust badges (“Used by 10,000+ businesses”)

- Before/After transformation visuals

- Time-saving emphasis (“Save 5+ hours instantly”)

- Simplicity bias (3-step workflow)

- Authority positioning (“AI-powered data cleaning engine”)
